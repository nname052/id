# خطة الأوديت الشامل (v40) — بطلب صاحب اللعبة

> الترتيب = الأولوية. كل بند: نفّذ → شغّل → بص (صورة) → اختبر → صلّح. اللي يخلص يتعلّم ✅ هنا وفي DEVELOPMENT_PROGRESS.

## 1. إحساس السواقة
- [x] ✅ **العربية "بتربش"**: قياس رعشة جسم العربية المرسوم (pitch/roll/heave) وهي ماشية على أسفلت مستوي بسرعات مختلفة، ومن الكاميرا اللي ورا وكرسي السواق. تحديد السبب (فيزيا العجل/المطبات/الـ interpolation/الكاميرا) وتصليحه. اختبار رقمي قبل/بعد.

## 2. الشرطة والإسعاف
- [x] ✅ مفيش غرامة/مطاردة من الشرطة لما إنت سايق البوكس أو الإسعاف وتخبط.
- [x] ✅ **المرور بيوسّع للسارينة**: لما سارينة الإسعاف/البوكس شغالة، العربيات اللي قدامك على نفس الطريق بتطلع على جنب وتهدّي لحد ما تعدي.
- [x] ✅ صوت السارينة لعربية اللاعب (إسعاف/شرطة) — يتأكد إنه شغال ومتغير (wail/yelp) ومش بيتقطع.
- [x] ✅ **عربية إسعاف واقعية**: مش هاي إس عادي — سقف عالي (high-roof)، شبابيك الصندوق مقفولة، حزام أخضر، "إسعاف"، كشاف على السقف العالي. مرجع: صور إسعاف مصر (مرخصة) للنسب والألوان.

- [ ] العمارات بتختفي/تظهر: الخرايط الصغيرة → كل المربعات تتحمّل مرة واحدة ومفيش unload.
