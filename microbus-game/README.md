# ميكروباص مصر 🚐 — نسخة تجريبية أولى (Prototype)

لعبة قيادة ميكروباص مصري 3D جوه المتصفح: شارع مصري واحد عالي التفاصيل بتقاطعين، إشارة مرور، عربيات ماشية ومركونة، مشاة، ومحلات بلافتات عربي.

## التشغيل (خطوات بسيطة)

**مرة واحدة بس:** نزّل **Node.js** (نسخة LTS) من https://nodejs.org وسطّبه عادي (Next → Next → Finish).

بعد كده:

1. افتح فولدر `microbus-game`.
2. **على الماك:** دبل كليك على `start.command`
   **على الويندوز:** دبل كليك على `start.bat`
   (أو افتح Terminal جوه الفولدر واكتب: `npm install` وبعدين `npm run dev`)
3. المتصفح هيفتح لوحده. لو مفتحش، افتح: **http://localhost:5173**
4. استنى التحميل، ودوس **اركب الميكروباص ▶**

> أفضل متصفح: **Chrome** أو **Edge** (محدّث). لازم كارت الشاشة يكون شغال (مش وضع توفير الطاقة).

## التحكم

| الزرار | الوظيفة |
|---|---|
| `W` | بنزين |
| `S` | فرامل، ولو واقف ودايس عليها → ريوس |
| `A` / `D` | دركسيون شمال / يمين |
| `Space` | فرامل يد |
| `C` | تغيير الكاميرا (السواق ← ورا ← خارجية قريبة ← سينمائية) |
| `R` | رجّع الميكروباص للطريق |
| `H` | كلاكس |
| `Q` / `E` | بص شمال / يمين (عشان المرايات) — أو اسحب بالماوس |
| `B` | بص ورا |
| `T` | نهار ← غروب ← ليل |
| `M` | كتم الصوت |
| `F` | عداد الـ FPS |
| `I` | إظهار/إخفاء المساعدة |

**Gamepad:** `RT` بنزين، `LT` فرامل، العصاية الشمال دركسيون، `A` فرامل يد، `B` كلاكس، `Y` كاميرا، `X` وقت اليوم، `Back` رجوع للطريق، العصاية اليمين تبص حواليك.

## إيه اللي في النسخة دي

- **فيزياء حقيقية** (`src/physics/VehiclePhysics.js`): وزن 2.35 طن، تعليق مستقل لكل عجلة (سوست ومساعدين)، انتقال وزن أثناء الفرملة والتسارع، Body roll، نموذج إطارات Pacejka، دائرة احتكاك، فرامل يد بتقفل العجل الورانية، فتيس أوتوماتيك 5 سرعات + ريوس، مقاومة هوا ودحرجة، تصادم مع الرصيف والعربيات.
  تقدر تختبرها من غير متصفح: `npm run test:physics`
- **الدركسيون**: حوالي 1.6 لفة لكل ناحية (نسبة توجيه 16.5:1)، بيلف بنعومة، وبيرجع للنص لوحده حسب سرعة العربية، والعجلتين قدام بيتوجهوا معاه.
- **منظور السائق**: الكاميرا مكان عين السواق، بتتأثر بالمطبات والفرملة والتسارع (قصور الراس)، والمرايات الجانبية بتعكس الشارع فعلًا.
- **الشارع**: أسفلت PBR، أرصفة بحروف أبيض وأسود، جزيرة وسطى بنخل، مطبات حقيقية (بتأثر على الفيزياء)، بلاعات وحفر، عمارات بلاستر وطوب أحمر، بلكونات، تكييفات، غسيل منشور، دشات وخزانات مية، محلات بلافتات عربي، يافطات عيادات، كشك، قهوة بكراسي بلاستيك، عربية فول، زينة رمضان، سلوك كهربا.
- **المرور**: عربيات بنموذج IDM بتقف في الأحمر وتمشي في الأخضر، بتسيب مسافة، سرعات مختلفة، وبتضرب كلاكس لو وقفت قدامها 😄
- **الصوت**: كله متولّد بالكود (موتور ديزل، كاوتش، فرامل، كلاكس، شارع) + صوت 3D للعربيات حواليك.
- **الوقت**: نهار / غروب / ليل (بأنوار الشارع والكشافات)، ونظام المطر/الأسفلت المبلول جاهز (`env.setWetness(1)` في الـ Console).

## هيكل المشروع

```
microbus-game/
├── index.html              الصفحة + شاشة البداية
├── assets/                 ← حط هنا موديلاتك وخاماتك وأصواتك (اختياري)
│   ├── models/  textures/  audio/
├── public/                 الخطوط العربية + ملفات PWA
├── src/
│   ├── main.js             نقطة البداية
│   ├── core/               Game loop + التحكم (Input)
│   ├── physics/            فيزياء الميكروباص + التصادم
│   ├── vehicles/           موديل الميكروباص (الهيكل + الصالون) + العربيات + العجل
│   ├── world/              الشارع، العمارات، الإكسسوارات، الإشارة، المشاة، السما
│   ├── traffic/            ذكاء المرور
│   ├── camera/             الكاميرات الأربعة
│   ├── audio/              الصوت
│   ├── render/             الخامات وتوليد الـ Textures
│   ├── assets/             قراية الـ GLB/الخامات/الأصوات
│   └── config/assets.config.js   ← أسماء ملفات الـ Assets وإعداداتها
└── tools/physics-test.mjs  اختبار الفيزياء
```

## نسخة للنشر / PWA
`npm run build` بيطلع فولدر `dist/` جاهز ترفعه على أي استضافة (Netlify، GitHub Pages...). فيه `manifest.webmanifest` و Service Worker، فممكن يتسطّب كتطبيق.
