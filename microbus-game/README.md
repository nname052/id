# ميكروباص مصر 🚐 — نسخة تجريبية أولى (Prototype)

لعبة قيادة ميكروباص مصري 3D جوه المتصفح (موبايل وكمبيوتر): مدينة وريف وصحرا وجبل، بدركسيون لمس دائري حقيقي وكاميرا من كرسي السواق.

## التشغيل (خطوات بسيطة)

**مرة واحدة بس:** نزّل **Node.js** (نسخة LTS) من https://nodejs.org وسطّبه عادي (Next → Next → Finish).

بعد كده:

1. افتح فولدر `microbus-game`.
2. **على الماك:** دبل كليك على `start.command`
   **على الويندوز:** دبل كليك على `start.bat`
   (أو افتح Terminal جوه الفولدر واكتب: `npm install` وبعدين `npm run dev`)
3. المتصفح هيفتح لوحده. لو مفتحش، افتح: **http://localhost:5173**
4. استنى التحميل، ودوس **اركب الميكروباص ▶**

> أفضل متصفح: **Chrome** أو **Edge** (محدّث). لازم كارت الشاشة يكون شغال (مش وضع توفير الطاقة).

## التحكم

### على الموبايل (لف التليفون بالعرض)
- **الدركسيون (شمال):** حط صباعك عليه ولفّه بحركة دائرية زي العربية الحقيقية. بيلف لحد 540° (لفة ونص) لكل ناحية. تقدر تشيل صباعك وتمسكه تاني من أي مكان من غير ما يقفز. لما تسيبه بيرجع للنص لوحده بالراحة (أسرع كل ما السرعة تزيد).
- **البنزين والفرامل (يمين):** الضغط تدريجي — كل ما تطلّع صباعك لفوق على الدواسة الضغط بيزيد.
- **الريوس:** دوس فرامل لحد ما تقف، وكمّل ضاغط ثانية تقريبًا → هتلاقي **R** وترجع لورا. البنزين بيرجعك **D**.
- **فوق على اليمين:** الكاميرا · الكشافات · نهار/غروب/ليل · رجوع للطريق. وجنب الدركسيون: كلاكس. وجنب الفرامل: فرامل يد **P**.

### على الكمبيوتر
| الزرار | الوظيفة |
|---|---|
| `W` | بنزين |
| `S` | فرامل، ولو واقف ودايس عليها → ريوس |
| `A` / `D` | دركسيون شمال / يمين |
| `Space` | فرامل يد |
| `C` | تغيير الكاميرا (السواق ← ورا ← خارجية قريبة ← سينمائية) |
| `R` | رجّع الميكروباص للطريق |
| `H` | كلاكس |
| `L` | الكشافات |
| `Q` / `E` | بص شمال / يمين — أو اسحب بالماوس |
| `B` | بص ورا |
| `T` | نهار ← غروب ← ليل |
| `M` | كتم الصوت · `F` عداد FPS · `I` المساعدة |

**Gamepad:** `RT` بنزين، `LT` فرامل، العصاية الشمال دركسيون، `A` فرامل يد، `B` كلاكس، `Y` كاميرا، `X` وقت اليوم، `Back` رجوع للطريق.

## الخريطة (حوالي 3.3 كم)
وسط البلد (إشارة مرور + شارع شعبي ضيق فيه جامع) ← حي سكني بيافطات اتجاهات ← الميدان (دوار بمسلة ونخل) ← كوبري النيل ← الطريق الزراعي جنب الترعة (نخل، حقول، أعمدة كهربا) ← القرية (بيوت طوب أحمر، جامع بمئذنة، مطبات) ← الطريق الصحراوي ← الطريق الجبلي ونفق ← الطريق السريع (فيه دوران للخلف) ← ترجع وسط البلد. الطريق مقفول، فتقدر تسوق على طول.

## الأداء على الموبايل
- الجودة بتتظبط لوحدها: لو الـ FPS نزل، اللعبة بتقلل الدقة والضلال وتحديث المرايات ومسافة الرؤية، ولما يتحسن بترجعها.
- العالم متقسم لقطع (Chunks) بتختفي لما تبعد، والنخل والشجر والأعمدة Instanced، والعربيات البعيدة من غير عجل ولا ضل.
- الشيدرز بتتجهز في شاشة التحميل عشان مفيش تقطيع أول ما تدخل منطقة جديدة.

## تحسين الشكل بموديلات حقيقية
شوف **[ASSETS.md](ASSETS.md)** — بيقولك اسم كل ملف، تحطه فين، وتجيبه منين مجانًا. اللعبة بتقراه تلقائيًا.

## نسخة للنشر / PWA
`npm run build` بيطلع فولدر `dist/` جاهز ترفعه على أي استضافة (Netlify، GitHub Pages...). فيه `manifest.webmanifest` و Service Worker، فممكن يتسطّب كتطبيق.

## الجديد (التحديث الكبير)
- **الهاي إس** هو عربيتك الوحيدة. في الركن فوق شمال لوحة تشخيص: `HIACE: LOADED` والمرايات `ACTIVE`.
- **المرايات الجانبية** بتظهر على حرف الشاشة بصورة حية (ممكن تقفلها من الإعدادات).
- **الإعدادات (⚙️)**: زاوية الرؤية، حساسية الكاميرا، الجودة، الضل، جودة المرايات، الوقت، الكشافات، الصوت، زحمة المرور، عدد الركاب. بتتحفظ على جهازك.
- **الرصيف** بيتطلع عليه بالعجل (بالراحة) والخبطة السريعة بتبان وتتسمع.
- **الركاب**: اقف عند "موقف" والباب الجرار (اليمين) ناحية الناس اللي بتشاور → الباب بيتفتح ويركبوا. كل راكب نازل موقف معين، وبيقولك "على جنب يا أسطى".
- **طرق فرعية**: طريق الترعة، مدق الصحراوي، مخرج الطريق السريع، الطريق الغربي، شارع الميدان، حارة المقابر — متوصلة ببعض ومفيش حيطان خفية.
- **ضرر**: خدوش، بعجات، فوانيس مكسورة، إكصدام متدلدل، شرخ في الزجاج. **R / ↺** بيصلّح.
- **انقلاب**: ممكن في الحالات الصعبة. لو اتقلبت دوس **R / ↺** عشان تعدلها مكانها.
- **الليل**: الكشافات بتنوّر الطريق، نور فرامل وريوس، العدادات منورة.
