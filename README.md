# مشهد (Mashhad): مولّد فيديوهات موشن جرافيك ومونتاج محلي

تطبيق ويب بيشتغل على الماك بس. بتكتب فكرة، والتطبيق يعمل فيديو موشن جرافيك قصير لتيك توك، وإنت بتوافق على كل مرحلة من الصفحة.

- **التصميم الكامل:** [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
- **المرحلة الحالية:** المرحلة 1 (التطبيق نفسه). المرحلة 0 (التجارب) في [`phase0/README.md`](phase0/README.md).

## التشغيل
```bash
./run.sh
```
بيفتح `http://127.0.0.1:8000`. أول مرة على جهاز جديد: `uv run python assets/fetch_assets.py` علشان المكتبات تتنزل.

## الفولدرات

| الفولدر | فيه إيه | مين بيحطه |
|---|---|---|
| `fonts/` | خطوط Reem Kufi و IBM Plex Sans Arabic | إنت |
| `reference/` | الفيديو المرجعي (HTML) | إنت |
| `music/` | ملفات موسيقى MP3 (اختياري) | إنت |
| `app/` | التطبيق: السيرفر، والمراحل، والمشغّل، والصفحات | الكود |
| `phase0/` | سكريبتات تجارب المرحلة 0 | الكود |
| `assets/` | مكتبات الرسومات والأيقونات والإيموجي (بتتنزل بالسكريبت، وبتكبر لوحدها) | السكريبت والتطبيق |
| `videos/` | الفيديوهات اللي بتتعمل | التطبيق (مش بيترفع على git) |
